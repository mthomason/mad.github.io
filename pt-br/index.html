MAD Designer

Criador de Relatórios de BI de Código Aberto para macOS, Windows & iOS

Crie e compartilhe relatórios personalizados de business intelligence em qualquer lugar. Conecte-se a PostgreSQL, MySQL, MariaDB, Microsoft SQL Server e SQLite; crie consultas visualmente ou em SQL; e exporte para PDF, HTML, CSV e JSON. Combine relatórios de vários bancos de dados em um único documento portátil com Relatórios de Composição. O mesmo engine roda sem interface no Linux e no Windows.

Baixar para macOS (.dmg) Baixar para Windows (.zip) Ver código-fonte no GitHub Documentação & Guias Patrocine o relançamento na App Store

As compilações para desktop não são assinadas; no Windows, o SmartScreen perguntará — escolha Mais informações → Executar mesmo assim (consulte o guia do Windows).

A interface do aplicativo está disponível em inglês, chinês simplificado, japonês, português do Brasil, alemão e espanhol latino-americano. As traduções são assistidas por máquina e podem conter erros; informe-os no rastreador de problemas.

O lançamento na App Store para iOS retorna no início de 2027. Os patrocinadores financiam o desenvolvimento e o relançamento.

Principais recursos

Conecte-se aos seus bancos de dados

Conecte-se com segurança a bancos de dados PostgreSQL, MySQL, MariaDB, Microsoft SQL Server e SQLite.

Designer de consultas poderoso

Crie consultas ad hoc com várias tabelas, junções, agrupamentos e filtros para obter exatamente os dados de que precisa.

Designer de relatórios completo

Crie relatórios bonitos com rótulos de dados, imagens, resumos e formatação personalizada.

Compartilhe & exporte

Compartilhe relatórios interativos com colegas ou exporte-os como PDFs para ampla distribuição.

Relatórios de Composição

Combine relatórios de vários bancos de dados em um único documento .mad. Cada origem mantém sua própria consulta, layout e dados, e o Resultado os une localmente.

Engine headless & CLI

O mesmo engine roda no Linux e no Windows por meio da CLI mad, e em CI por meio do mad-action.

Formato .mad aberto

Um arquivo .mad contém o esquema, a consulta e o layout em um único documento portátil com especificação aberta.

Seis idiomas de interface

Inglês, chinês simplificado, japonês, português do Brasil, alemão e espanhol latino-americano. As traduções são assistidas por máquina.
