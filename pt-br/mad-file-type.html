Extensão de arquivo .mad

O que é um arquivo .mad?

Um arquivo .mad é um Mobile Analytics Document criado pelo MAD Designer, uma ferramenta de business intelligence para iOS e macOS. Esses arquivos armazenam a definição completa de um relatório de análise móvel, incluindo conexões de fontes de dados, informações de consulta e o layout do próprio relatório.

Mais informações

O formato de arquivo .mad é central para o aplicativo MAD Designer. Ele permite que os usuários projetem, salvem e compartilhem relatórios interativos. Cada arquivo .mad é um pacote autocontido que inclui:

  • Detalhes da conexão de dados: Informações sobre como se conectar ao banco de dados subjacente, como PostgreSQL, MySQL, MariaDB, Microsoft SQL Server ou SQLite.
  • Definições de consulta: As consultas SQL usadas para recuperar dados do relatório.
  • Layout do relatório: O design visual do relatório, incluindo a posição de gráficos, tabelas, rótulos e imagens.
  • Regras de formatação: Formatação personalizada aplicada a campos de dados e outros elementos.

Como os arquivos .mad reúnem todos os componentes necessários, eles são altamente portáteis. Um usuário pode criar um relatório no Mac e compartilhar o arquivo .mad com um colega, que pode então abrir e visualizar o relatório interativo no iPhone ou iPad.

A especificação .mad completa e a documentação para desenvolvedores são abertas e publicadas separadamente.

Como abrir um arquivo .mad

Você pode abrir arquivos .mad com o aplicativo MAD Designer. As compilações nativas para macOS e Windows já estão disponíveis; o lançamento na App Store para iOS retorna no início de 2027.
