MAD Designer

macOS、Windows、iOS 向けのオープンソース BI レポートビルダー

カスタムのビジネスインテリジェンスレポートをどこでも設計・共有できます。PostgreSQL、MySQL、MariaDB、Microsoft SQL Server、SQLite に接続し、クエリをビジュアルまたは SQL で作成し、PDF、HTML、CSV、JSON にエクスポートできます。同じエンジンは Linux と Windows でヘッドレスでも動作します。

macOS 版をダウンロード（.dmg） Windows 版をダウンロード（.zip） GitHub でソースを見る ドキュメントとガイド App Store 復帰を支援する

Homebrew でインストール: brew install --cask mthomason/tap/mad-designer • サンプルレポート: London.mad · Music.mad

バージョン: アプリ {{ site.data.versions.macos_app_version }} / エンジン {{ site.data.versions.engine_version }}（{{ site.data.versions.engine_revision }}）。デスクトップ版は署名されていないため、Windows では SmartScreen が確認を求めます —「詳細情報」→「実行」を選択してください（Windows ガイドを参照）。

アプリケーションの UI は、英語、簡体字中国語、日本語、ブラジルポルトガル語、ドイツ語、ラテンアメリカスペイン語で利用できます。翻訳は機械支援によるもので、誤りを含む場合があります。誤りは課題トラッカーで報告してください。

iOS App Store でのリリースは 2027 年初頭に再開されます。スポンサーが開発と復帰を資金面で支えています。

主な機能

データベースに接続

PostgreSQL、MySQL、MariaDB、Microsoft SQL Server、SQLite のデータベースに安全に接続できます。

強力なクエリデザイナー

複数のテーブル、結合、グループ化、フィルターを使ってアドホッククエリを作成し、必要なデータを正確に取得できます。

充実したレポートデザイナー

データラベル、画像、集計、カスタム書式を使って美しいレポートを作成できます。

共有とエクスポート

インタラクティブなレポートを同僚と共有したり、PDF としてエクスポートして広く配布したりできます。

ヘッドレスエンジンと CLI

同じエンジンが mad CLI を通じて Linux と Windows で、また CI では mad-action を通じて動作します。

オープンな .mad 形式

.mad ファイルは、スキーマ、クエリ、レイアウトを 1 つのポータブルなドキュメントに収め、仕様は公開されています。

6 つの UI 言語

英語、簡体字中国語、日本語、ブラジルポルトガル語、ドイツ語、ラテンアメリカスペイン語。翻訳は機械支援によるものです。

プロフェッショナルのために設計

ビジネスアナリスト

生データを明確で実用的な洞察に変換し、ビジネス上の意思決定を推進します。

データプロフェッショナルと開発者

データベース接続をすばやくテストし、クエリを実行し、エンドユーザーにデータソリューションを提供します。

MAD の上に構築

契約を読む

形式仕様、データオブジェクトの設計、開発者ガイド。

ヘッドレスで実行

mad CLI と mad-action は、UI なしでチェックイン済みのレポートを実行します。
