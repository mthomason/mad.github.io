.mad ファイル拡張子

.mad ファイルとは？

.mad ファイルは、iOS および macOS 向けのビジネスインテリジェンスツールである MAD Designer が作成する Mobile Analytics Document です。このファイルには、データソース接続、クエリ情報、レポート自体のレイアウトなど、モバイル分析レポートの完全な定義が保存されます。

詳細情報

.mad ファイル形式は MAD Designer アプリケーションの中心です。ユーザーはインタラクティブなレポートを設計、保存、共有できます。各 .mad ファイルは、以下を含む自己完結型のパッケージです。

  • データ接続の詳細: PostgreSQL、MySQL、MariaDB、Microsoft SQL Server、SQLite など、基盤となるデータベースへの接続方法に関する情報。
  • クエリ定義: レポートのデータを取得するために使用する SQL クエリ。
  • レポートレイアウト: グラフ、表、ラベル、画像の配置を含む、レポートの視覚的なデザイン。
  • 書式ルール: データフィールドやその他の要素に適用されるカスタム書式。

.mad ファイルは必要なコンポーネントをすべてまとめているため、高いポータビリティがあります。ユーザーは Mac でレポートを作成し、その .mad ファイルを同僚と共有できます。同僚は iPhone や iPad でそのインタラクティブなレポートを開いて閲覧できます。

完全な .mad 仕様と開発者向けドキュメント はオープンで、別途公開されています。

.mad ファイルを開く方法

.mad ファイルは MAD Designer アプリケーションで開くことができます。ネイティブの macOS 版と Windows 版は現在利用可能です。iOS App Store でのリリースは 2027 年初頭に再開されます。
