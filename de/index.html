MAD Designer

Open-Source-BI-Berichtsgenerator für macOS, Windows & iOS

Entwerfen und teilen Sie individuelle Business-Intelligence-Berichte überall. Stellen Sie Verbindungen zu PostgreSQL, MySQL, MariaDB, Microsoft SQL Server und SQLite her; erstellen Sie Abfragen visuell oder in SQL und exportieren Sie nach PDF, HTML, CSV und JSON. Dieselbe Engine läuft headless unter Linux und Windows.

Für macOS herunterladen (.dmg) Für Windows herunterladen (.zip) Quellcode auf GitHub ansehen Dokumentation & Anleitungen App-Store-Neustart unterstützen

Installation über Homebrew: brew install --cask mthomason/tap/mad-designer • Beispielberichte: London.mad · Music.mad

Die Desktop-Builds sind nicht signiert; unter Windows wird SmartScreen nachfragen — wählen Sie „Weitere Informationen“ → „Trotzdem ausführen“ (siehe die Windows-Anleitung).

Die Benutzeroberfläche der Anwendung ist in Englisch, vereinfachtem Chinesisch, Japanisch, brasilianischem Portugiesisch, Deutsch und lateinamerikanischem Spanisch verfügbar. Die Übersetzungen sind maschinell unterstützt und können Fehler enthalten; melden Sie diese bitte im Issue-Tracker.

Die iOS-App kehrt Anfang 2027 in den App Store zurück. Sponsoren finanzieren die Entwicklung und den Neustart.

Hauptfunktionen

Mit Ihren Datenbanken verbinden

Stellen Sie sichere Verbindungen zu PostgreSQL-, MySQL-, MariaDB-, Microsoft SQL Server- und SQLite-Datenbanken her.

Leistungsstarker Abfrage-Designer

Erstellen Sie Ad-hoc-Abfragen mit mehreren Tabellen, Joins, Gruppierungen und Filtern, um genau die Daten zu erhalten, die Sie benötigen.

Umfangreicher Berichts-Designer

Erstellen Sie ansprechende Berichte mit Datenbeschriftungen, Bildern, Zusammenfassungen und benutzerdefinierter Formatierung.

Teilen & Exportieren

Teilen Sie interaktive Berichte mit Kollegen oder exportieren Sie sie als PDFs für eine breite Verteilung.

Headless-Engine & CLI

Dieselbe Engine läuft über die mad-CLI unter Linux und Windows und über mad-action in CI.

Offenes .mad-Format

Eine .mad-Datei enthält das Schema, die Abfrage und das Layout in einem portablen Dokument mit offener Spezifikation.

Sechs UI-Sprachen

Englisch, vereinfachtes Chinesisch, Japanisch, brasilianisches Portugiesisch, Deutsch und lateinamerikanisches Spanisch. Die Übersetzungen sind maschinell unterstützt.
