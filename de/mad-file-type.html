.mad-Dateierweiterung

Was ist eine .mad-Datei?

Eine .mad-Datei ist ein Mobile Analytics Document, das von MAD Designer erstellt wird, einem Business-Intelligence-Tool für iOS und macOS. Diese Dateien enthalten die vollständige Definition eines mobilen Analyseberichts, einschließlich Datenquellenverbindungen, Abfrageinformationen und des Layouts des Berichts selbst.

Weitere Informationen

Das .mad-Dateiformat ist zentral für die MAD Designer-Anwendung. Es ermöglicht Benutzern, interaktive Berichte zu entwerfen, zu speichern und zu teilen. Jede .mad-Datei ist ein eigenständiges Paket, das Folgendes enthält:

  • Verbindungsdetails: Informationen zur Verbindung mit der zugrunde liegenden Datenbank, etwa PostgreSQL, MySQL, MariaDB, Microsoft SQL Server oder SQLite.
  • Abfragedefinitionen: Die SQL-Abfragen, mit denen Daten für den Bericht abgerufen werden.
  • Berichtslayout: Das visuelle Design des Berichts, einschließlich der Platzierung von Diagrammen, Tabellen, Beschriftungen und Bildern.
  • Formatierungsregeln: Benutzerdefinierte Formatierung, die auf Datenfelder und andere Elemente angewendet wird.

Da .mad-Dateien alle notwendigen Komponenten bündeln, sind sie sehr portabel. Ein Benutzer kann einen Bericht auf seinem Mac erstellen und die .mad-Datei mit einem Kollegen teilen, der den interaktiven Bericht dann auf seinem iPhone oder iPad öffnen und ansehen kann.

Die vollständige .mad-Spezifikation und Entwicklerdokumentation sind offen und separat veröffentlicht.

So öffnen Sie eine .mad-Datei

Sie können .mad-Dateien mit der Anwendung MAD Designer öffnen. Die nativen Builds für macOS und Windows sind jetzt verfügbar; die Veröffentlichung im iOS App Store kehrt Anfang 2027 zurück.
