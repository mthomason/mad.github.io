MAD Designer

Creador de informes de BI de código abierto para macOS, Windows e iOS

Diseñe y comparta informes de inteligencia de negocios personalizados en cualquier lugar. Conéctese a PostgreSQL, MySQL, MariaDB, Microsoft SQL Server y SQLite; cree consultas visualmente o en SQL; y exporte a PDF, HTML, CSV y JSON. Combine informes de varias bases de datos en un solo documento portátil con Informes de composición. El mismo motor se ejecuta sin interfaz en Linux y Windows.

Características principales

Conéctese a sus bases de datos

Conéctese de forma segura a bases de datos PostgreSQL, MySQL, MariaDB, Microsoft SQL Server y SQLite.

Diseñador de consultas potente

Cree consultas ad hoc con múltiples tablas, uniones, agrupaciones y filtros para obtener exactamente los datos que necesita.

Diseñador de informes completo

Cree informes atractivos con etiquetas de datos, imágenes, resúmenes y formato personalizado.

Compartir y exportar

Comparta informes interactivos con sus colegas o expórtelos como PDF para una amplia distribución.

Informes de composición

Combine informes de varias bases de datos en un solo documento .mad. Cada origen conserva su propia consulta, diseño y datos, y el Resultado los une localmente.

Motor sin interfaz y CLI

El mismo motor se ejecuta en Linux y Windows a través de la CLI mad, y en CI a través de mad-action.

Formato abierto .mad

Un archivo .mad contiene el esquema, la consulta y el diseño en un solo documento portátil con una especificación abierta.

Seis idiomas de interfaz

Inglés, chino simplificado, japonés, portugués de Brasil, alemán y español latinoamericano. Las traducciones son asistidas por máquina.
