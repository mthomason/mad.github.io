Extensión de archivo .mad

¿Qué es un archivo .mad?

Un archivo .mad es un documento de analítica móvil (Mobile Analytics Document) creado por MAD Designer, una herramienta de inteligencia de negocios para iOS y macOS. Estos archivos almacenan la definición completa de un informe de analítica móvil, incluidas las conexiones a las fuentes de datos, la información de las consultas y el diseño del informe en sí.

Más información

El formato de archivo .mad es fundamental para la aplicación MAD Designer. Permite a los usuarios diseñar, guardar y compartir informes interactivos. Cada archivo .mad es un paquete autocontenido que incluye:

  • Detalles de conexión a los datos: Información sobre cómo conectarse a la base de datos subyacente, como PostgreSQL, MySQL, MariaDB, Microsoft SQL Server o SQLite.
  • Definiciones de consultas: Las consultas SQL utilizadas para recuperar los datos del informe.
  • Diseño del informe: El diseño visual del informe, incluida la ubicación de gráficos, tablas, etiquetas e imágenes.
  • Reglas de formato: El formato personalizado aplicado a los campos de datos y otros elementos.

Como los archivos .mad reúnen todos los componentes necesarios, son muy portátiles. Un usuario puede crear un informe en su Mac y compartir el archivo .mad con un colega, quien luego puede abrirlo y ver el informe interactivo en su iPhone o iPad.

La especificación completa de .mad y la documentación para desarrolladores son abiertas y se publican por separado.

Cómo abrir un archivo .mad

Puede abrir archivos .mad con la aplicación MAD Designer. Las compilaciones nativas para macOS y Windows ya están disponibles; la versión de iOS para la App Store regresa a principios de 2027.
