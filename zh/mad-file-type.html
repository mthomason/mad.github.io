.mad 文件扩展名

什么是 .mad 文件？

.mad 文件是由 MAD Designer 创建的移动分析文档（Mobile Analytics Document），MAD Designer 是一款面向 iOS 和 macOS 的商业智能工具。这些文件存储移动分析报表的完整定义，包括数据源连接、查询信息以及报表本身的布局。

更多信息

.mad 文件格式是 MAD Designer 应用程序的核心。它允许用户设计、保存和共享交互式报表。每个 .mad 文件都是一个自包含的包，包含：

  • 数据连接详细信息：有关如何连接到基础数据库的信息，例如 PostgreSQL、MySQL、MariaDB、Microsoft SQL Server 或 SQLite。
  • 查询定义：用于检索报表数据的 SQL 查询。
  • 报表布局：报表的视觉设计，包括图表、表格、标签和图像的放置。
  • 格式规则：应用于数据字段和其他元素的自定义格式。

由于 .mad 文件捆绑了所有必要的组件，因此它们具有高度的可移植性。用户可以在其 Mac 上创建报表，并将 .mad 文件与同事共享，同事随后可以在其 iPhone 或 iPad 上打开并查看交互式报表。

.mad 文件也可以是一个组合报表：一个将多个报表合并在一起的文档。每个来源保留自己的数据库连接、查询、布局和数据，结果会在 SQLite 中本地连接它们的物化表——因此单个便携式文件无需联合服务器即可涵盖 MySQL、PostgreSQL、SQL Server 和 SQLite。组合报表在适用于 macOS 和 Windows 的 MAD Designer 0.8 中提供。

完整的 .mad 规范和开发者文档 是开放的，并单独发布。
