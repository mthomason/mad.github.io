MAD Designer

适用于 macOS、Windows 和 iOS 的开源 BI 报表构建工具

随时随地设计和共享自定义商业智能报表。连接 PostgreSQL、MySQL、MariaDB、Microsoft SQL Server 和 SQLite；以可视化方式或使用 SQL 构建查询；并导出为 PDF、HTML、CSV 和 JSON。同一引擎可在 Linux 和 Windows 上以无头方式运行。

下载 macOS 版（.dmg） 下载 Windows 版（.zip） 在 GitHub 上查看源代码 文档与指南 赞助 App Store 重新上架

通过 Homebrew 安装：brew install --cask mthomason/tap/mad-designer • 示例报表：London.mad · Music.mad

版本：应用 {{ site.data.versions.macos_app_version }} / 引擎 {{ site.data.versions.engine_version }}（{{ site.data.versions.engine_revision }}）。桌面版构建未签名；在 Windows 上，SmartScreen 会发出询问——请选择“更多信息”→“仍要运行”（参见 Windows 指南）。

应用程序界面提供英语、简体中文、日语、巴西葡萄牙语、德语和拉丁美洲西班牙语版本。翻译为机器辅助完成，可能包含错误；请在问题跟踪器中报告。

iOS App Store 版本将于 2027 年初回归。赞助者资助开发和重新上架。

主要功能

连接您的数据库

安全连接至 PostgreSQL、MySQL、MariaDB、Microsoft SQL Server 和 SQLite 数据库。

强大的查询设计器

使用多表、连接、分组和筛选器构建即席查询，获取您所需的确切数据。

丰富的报表设计器

使用数据标签、图像、汇总和自定义格式创建精美的报表。

共享与导出

与同事共享交互式报表，或将其导出为 PDF 以便广泛分发。

无头引擎与 CLI

同一引擎通过 mad CLI 在 Linux 和 Windows 上运行，并通过 mad-action 在 CI 中运行。

开放的 .mad 格式

.mad 文件将模式、查询和布局保存在一个具有开放规范的便携式文档中。

六种界面语言

英语、简体中文、日语、巴西葡萄牙语、德语和拉丁美洲西班牙语。翻译为机器辅助完成。
